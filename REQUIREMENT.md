Full Stack Engineer Assignment – Secure File Storage Service
Intermediate
Build a secure file storage application where authenticated users can upload, manage, and share files. Users should be able to register, log in, upload files, organize them in their personal dashboard, and control whether each file is public or private. Public files should be accessible via a shareable link, while private files must only be accessible to their owner through proper authorization. The application should support uploading files of at least 100 MB while providing appropriate validation, upload progress, and error handling.

What to build

This assignment is designed to assess your full stack engineering skills through a real-world use case. We are looking for a secure, scalable, and maintainable implementation that demonstrates strong backend fundamentals, thoughtful API design, proper authentication and authorization, and clean frontend integration. While additional features and enhancements are always welcome, our primary focus is on the quality of your implementation, engineering decisions, and overall code craftsmanship.
Expectations

We expect a production-quality implementation that demonstrates clean architecture, secure authentication and authorization, well-designed APIs, proper validation, effective error handling, and a maintainable codebase. Prioritize correctness, scalability, and code quality over feature quantity. Additional features and enhancements are welcome, but the core requirements should be implemented to a high standard.
